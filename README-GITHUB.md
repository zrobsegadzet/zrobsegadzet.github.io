# Zrób Se Gadżet — klasyczny eksport

To jest zwykła wielostronicowa strona HTML/CSS z lekkim JavaScriptem wyłącznie do menu mobilnego i powiększania galerii. Możesz otworzyć `index.html` dwuklikiem, a do GitHub Pages wgrać całą zawartość tego folderu.

W GitHubie włącz Pages z gałęzi `main` i katalogu `/root`. W OVH ustaw rekordy DNS wskazane przez GitHub. Nie ma PHP, Reacta, bazy danych ani formularza serwerowego. Kontakt prowadzi przez e-mail.
